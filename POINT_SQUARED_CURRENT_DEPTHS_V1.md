This document records the locked Hollow Grove extension that turns Point², Current depths, Aura illumination, capacity growth, and stabilization into enforceable code.

It extends the existing semantic foundation. It does not replace the frozen Version 1.1 execution path or the existing Hollow Grove contract.

## Root Doctrine

Hollow Current holds.
Current flows.
Abyss feels.
Aura reveals.
Point² expands the self and the world together.

## Point and Point²

- `Point = Hueman + currently reachable world`
- `Point² = ascended state in which the Hueman and reachable world expand together`
- `Point -> Synthesis -> Point² -> stabilization -> new Point`

Canonical consequence after a legal landed Point²:

- `Current Capacity += 1`
- `Aura Capacity += 1`

Point² opens new developmental circles. It does not automatically maximize development, grant the next Frame, or introduce extra higher-point states.

## Current Depths

- `Hollow Current = Stonebend = life held in form`
- `Current = derivative between Stonebend and Glaüshouse = blood, heartbeat, circulation, living movement`
- `Current Speed = the operating tempo of Current`
- `Abyss = Glaüshouse = pain, pressure, hidden damage, recovery state, inward bodily feeling`

Material distinction remains locked:

- `Current = blood`
- `Hollow = pus / extracted interior resource`
- `Aura = air / pressure / light`
- `Hollow Current != Hollow`

## Aura Illumination

- `Aura Shine = outward presence`
- `Aura View = surrounding world and reachable horizon`
- `Inner Aura = inward identity, emotion, memory, and clarity`

Aura reveals every Current depth. Aura does not become another Current depth.

Point² expands the circles. Development fills the circles.
