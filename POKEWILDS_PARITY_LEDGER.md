# PokéWilds Behavioral Parity Ledger

PokéWilds is used as an external executable behavioral specification for the
Hollow Grove Hueman Alt Layer. Hollow Grove reproduces selected observable
mechanics through original Rust and Godot implementation.

PokéWilds source code, executable files, Pokémon assets, names, audio, fonts,
story content, and proprietary data are not canonical Hollow Grove components
and are not release dependencies.

## Authority Boundary

- Rust owns authoritative gameplay state and resolution.
- Godot collects input and presents authoritative results.
- External PokéWilds material is never required at runtime.

## Evidence Rules

- `Implemented/tested` means the Hollow Grove behavior exists and has
  deterministic tests; it does not claim exact PokéWilds parity until an
  observation record is attached.
- `Planned` means this ledger names a translation boundary only. A downloaded
  executable or asset never proves a Hollow Grove capability.
- Observable PokéWilds behavior is recorded from the external v0.8.11 Linux
  runtime and its included `README.txt`. No upstream file is copied here.
