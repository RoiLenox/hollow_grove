HOLLOW GROVE BEING / OBJECT ONTOLOGY

Being:
Living practiced Hueman identity

Object:
External addressable thing or construct

Skill:
Practiced relation between Being and Object

Move:
Form- or Frame-specific expression of Skill on Object

Hollowing:
Refines Being or Object without crossing the boundary

Synthesis:
Allows qualities to cross between Being and Object

Addressing:
Proxy = immediate Object
Moxy = what the Object connects toward
Foxy = inverse/reflected/return Object relation

Canonical doctrine:
Being acts.
Object receives or participates.
Skill relates them.
Move expresses the relation.
Hollowing perfects a side.
Synthesis crosses the boundary.
