# How to Use the Ancestral Atlas

Status: Working creator and tool guidance

## Begin with a design question

Ask:

- What historical Gifts support this district?
- Which Point introduced this institution?
- Which ancestors influenced this profession?
- What architectural principles belong here?
- Which symbols are appropriate?
- Which historical collapse or failure does this House remember?
- What book belongs in this curriculum?
- How does this manifestation connect to locked canon?
- Is this design inherited, constitutional, or merely aesthetic?

## Trace before decorating

1. Name the owning House and current canon authority.
2. Find the House feature in its [cultural synthesis](houses/README.md).
3. Follow cited Points to the source assignments, then check Point type, temporal fit, and the culture-specific relevance range.
4. Select concrete IDs from the [Gifts Registry](ANCESTRAL_GIFTS_REGISTRY.md).
5. Reuse a Working entry in the [Manifestations Registry](ANCESTRAL_MANIFESTATIONS_REGISTRY.md), or record a bounded new proposal.
6. Translate it through existing geography, materials, visual law, institutions, and technology.
7. Add an ancestral provenance block.
8. Keep uncertainty and secondary-study status visible.

## Classification check

- **Inherited** explains why a design vocabulary exists.
- **Constitutional** identifies which present authority permits or constrains it.
- **Aesthetic** affects presentation only and grants no authority.
- **Gameplay reference** is a future hook until an existing runtime owner lawfully consumes it.

Random historical decoration fails this check when it has no Point, Gift, manifestation, or present canon connection.

## Design review questions

- Is the source culture primary at this Point, or a secondary study?
- Is the source culture fully contemporary, emergent, partial, boundary, or legacy within the Point?
- Does the feature flatten a complex culture into one stereotype?
- Does it copy a monument or costume when a design principle would suffice?
- Does it accidentally create an office, law, institution, permission, or gameplay capability?
- Does it use the locked visual foundation and House palette?
- Can a reader follow every Gift and manifestation ID back to a Point?
