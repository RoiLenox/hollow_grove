# Age II / Point XII Dossier Batch

Reviewed working dossiers for **Christian Empire (313–476 CE)**. The four assignments share a comparison window but are not synchronous states: Roman imperial transformation, Christian institutional consolidation, Constantinople's eastern continuity, and mature Sasanian development follow different internal clocks.

## Boundary rules

- 313 is a legal and political turning point, not instant universal Christianization.
- The western Roman terminal event in 476 does not end eastern Roman or Sasanian histories.
- Religious plurality, coercion, dissent, and regional difference remain visible.
