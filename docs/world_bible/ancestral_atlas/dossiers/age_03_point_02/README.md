## Boundary rules

- Muhammad's ministry, the Rashidun succession, and Umayyad rule are distinct phases.
- Early caliphate expansion did not erase local languages, religions, cities, or institutions.
- Byzantine and Sasanian war exhaustion is a context, not a single-cause explanation for Islamic expansion.
- Syriac scholarship is not reducible to a later translation movement, and Tang China is not a passive endpoint of trade.
