## Boundary rules

- The Carolingian imperial coronation in 800 is not a universal restoration of Rome.
- Abbasid Baghdad's scholarly prominence is not identical with one centralized “translation movement.”
- Byzantine iconoclasm and frontier recovery are phased controversies, not a single cultural break.
- Viking mobility includes trade, settlement, diplomacy, and service as well as raiding.
