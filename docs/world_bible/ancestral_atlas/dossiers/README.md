# Historical Dossiers

Status: source-reviewed research layer beneath Working Atlas assignments

Historical dossiers separate three things that must not be collapsed:

1. **Historical evidence** — archaeology, inscriptions, objects, and secure chronology.
2. **Scholarly interpretation** — modern arguments that organize incomplete evidence.
3. **Hollow Grove adaptation** — reviewable Gifts and manifestations constrained by existing canon.

A completed dossier does not make its Point assignment Canonical. It makes the
evidence, inference, uncertainty, and design provenance inspectable.
