Reviewed working dossiers for **Successor Kingdoms (476–610 CE)**. The window is deliberately non-synchronous: eastern Roman continuity, Merovingian Frankish rule, monastic networks, and Sasanian reform and frontier pressure follow different clocks.

## Boundary rules

- 476 is a western imperial succession marker, not the end of Roman history.
- “Franks” names changing Merovingian polities and communities, not a modern nation-state.
- Monastic Christianity contains diverse eastern and western ascetic traditions.
- Sasanian reform is phased through Kawād I and Khusrow I; it is not one instantaneous centralized system.
