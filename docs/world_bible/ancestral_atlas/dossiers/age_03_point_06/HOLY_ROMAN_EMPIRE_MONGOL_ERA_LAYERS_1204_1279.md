# Holy Roman Empire — Mongol-Era Layers (1204–1279)

Reviewed dossier for Age III, Point 6A. The Empire remained a negotiated field of emperor, princes, bishops, cities, guilds, and local courts. This dossier supports layered sovereignty, municipal/legal plurality, and guild traditions as bounded Hollow Grove inheritance lenses; it does not import imperial authority.

Sources: [Britannica — Holy Roman Empire](https://www.britannica.com/place/Holy-Roman-Empire); [New Cambridge Medieval History](https://www.cambridge.org/core/books/new-cambridge-medieval-history/).
